# spacerep v1.0.0
Publishing & Sharing

- Click the **Publish** button on the artifact
- You get a public URL — anyone with that link can use SpaceRep
- Each person's private cards and progress are stored separately

**Backing Up** Your Cards
In case losing cards when new version released: 

- Open the app → 📤 Export tab
- Click 💾 Download Backup → saves a .json file to your device
- Keep that file safe

**Restore** your cards first (💾 Download Backup)
- Open the new URL, go to 📤 Export → 📂 Restore from Backup → select your .json file
